TENTANG KOMPETISI

CTF SMK SWADHIPA 2 NATAR adalah ajang kompetisi keamanan siber berbasis *Jeopardy* yang dirancang untuk menguji, mengasah, serta membuktikan keahlian dalam bidang peretasan etis (*ethical hacking*).

Sistem Jeopardy

Peserta akan diberikan berbagai tantangan dengan bobot nilai beragam. Temukan flag dalam format SWADHIPA{...} untuk mengumpulkan poin tertinggi.

Peserta Target

Terbuka untuk Siswa SMA/SMK sederajat, Mahasiswa, hingga Komunitas Umum yang berdomisili di Lampung maupun seluruh Indonesia secara Online/Hybrid.

Fasilitas & Relasi

Mendapatkan Sertifikat Digital, Pengalaman Praktis Cyber Security, Networking antar cyber enthusiast, serta Total Hadiah Jutaan Rupiah.

KATEGORI TANTANGAN

Variasi tantangan yang menguji spektrum keahlian teknologi informasi dan keamanan sistem secara komprehensif.

Web Exploitation

Eksploitasi kerentanan aplikasi web seperti SQL Injection, XSS, CSRF, Local File Inclusion (LFI), dan Bypassing Authentication.

Reverse Engineering

Menganalisis kode biner terkompilasi, melacak alur eksekusi aplikasi, decompiling, dan mencari mekanisme perlindungan program.

Cryptography

Memecahkan pesan terenkripsi, kelemahan algoritma kriptografi klasik & modern, RSA, AES, serta penyalahgunaan fungsi Hash.

Digital Forensics

Analisis file dump memori, file pcap jaringan, gambar Steganografi tersembunyi, serta jejak digital (*digital artifacts*).

Binary Exploitation (Pwn)

Mengeksploitasi aplikasi tingkat rendah (*low-level*), Buffer Overflow, ROP Chain, Format String, dan manipulasi memori.

OSINT

Investigasi informasi dari sumber terbuka (*Open Source Intelligence*), mengumpulkan jejak entitas dari dunia maya.
